PITHUB CAPABILITIES

Current Features of PitHub.

A central location for course videos, documents, playlists, and shared academic resources.

Video Hosting

Upload and access instructional videos in a centralized location. Video entries can be associated with the class or playlist where they are used.

Class Organization

Create class pages with course information and related learning materials. Keep resources grouped by course instead of searching through unrelated files.

Playlists

Collect related resources in a playlist. Private playlists can support controlled collaboration with invited members and assigned permissions.

Document Sharing

Share course documents alongside videos so students can find different types of learning materials in one place.

Search Functionality

Search for videos, classes, and users to make relevant academic resources easier to discover.

Public and Private Resources

Choose whether a class or playlist is public or private. Playlist permissions can control whether invited members can view, upload, or delete content.
