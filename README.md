# PitHub – Academic Resource Hub

## About the Website

The PitHub website serves as an informational platform for the Lewis University community. It introduces PitHub, a centralized academic resource hub designed to help faculty and staff upload, organize, manage, and share instructional videos and documents.

This website provides information about PitHub's features, registration process, technology stack, and development team. It also serves as a starting point for prospective users who want to learn more about the platform or access the PitHub application.

## Key Information About PitHub

- **Registration:** PitHub is currently available to Lewis University faculty and staff.
- **Account Access:** Prospective users must complete the PitHub Registration Form. Once registered using their Lewis University email, they can sign in and access the platform.
- **Content Organization:** Users must create a class or playlist before uploading instructional materials.
- **Supported Content:** Instructional videos and common document formats, including PDF, DOCX, and PPTX.
- **Privacy:** Classes can be public or private, while playlists are always private.
- **Playlist Permissions:** Playlist owners can invite other users and assign View Only, Post, or Delete permissions.
- **Content Management:** Users can edit and delete their own uploaded content.
- **Resource Sharing:** Faculty can share direct links to uploaded content. Students do not need a PitHub account to access shared links.
- **Search:** Users can search for classes, documents, and other users, subject to public visibility settings.
